{% trans %}About ChessFEN{% endtrans %}

{% trans %}ChessFEN is a small, self-hostable tool for chess encodings: recognize a position from a board image, browse PGN games and export Full FENs, and render any Placement or Full FEN as a board image. It runs on CPU, ships as one Docker image, and offers the same features through a web interface and an API.{% endtrans %}

{% trans %}Self-deploy{% endtrans %}

{% trans %}Run your own instance with Docker Compose. The image bakes in the pinned recognition model at build time.{% endtrans %}

git clone https://github.com/SidneyLYZhang/chessfen.git
cd chessfen
ADMIN_PASSWORD='replace-with-a-strong-password' SECRET_KEY='replace-with-a-long-random-secret' docker compose up --build

{% trans %}Then open http://localhost:8000 and create API keys on the admin page. The container serves plain HTTP; put it behind your own reverse proxy for TLS. Set DATABASE_URL to use PostgreSQL instead of the SQLite volume.{% endtrans %}
