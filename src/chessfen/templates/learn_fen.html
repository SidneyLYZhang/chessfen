{% trans %}Piece placement{% endtrans %}

{% trans %}A FEN string starts with the piece placement: eight ranks from rank 8 down to rank 1, separated by /.{% endtrans %}

{% trans %}Uppercase letters stand for White pieces (K, Q, R, B, N, P) and lowercase letters for Black pieces. Digits encode runs of empty squares.{% endtrans %}

{% trans %}Placement{% endtrans %} 
rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR

{% trans %}That is the starting position.{% endtrans %}

{% trans %}The other five fields{% endtrans %}

{% trans %}A complete FEN adds five space-separated fields: the side to move (w or b), castling rights (KQkq, or - for none), an en passant target square (or -), the halfmove clock, and the fullmove number.{% endtrans %}

{% trans %}Full FEN{% endtrans %} 
rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1
{% trans %}Term{% endtrans %}{% trans %}Example{% endtrans %}{% trans %}Meaning{% endtrans %}
{% trans %}Placement{% endtrans %}rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR{% trans %}Where the pieces stand; eight ranks from rank 8 down to rank 1, joined by /.{% endtrans %}
{% trans %}Side to move{% endtrans %}w{% trans %}w for White; b for Black.{% endtrans %}
{% trans %}Castling rights{% endtrans %}KQkq{% trans %}Castling availability: K and Q for White, k and q for Black; - when none.{% endtrans %}
{% trans %}En passant{% endtrans %}-{% trans %}The target square after a double pawn push, or -.{% endtrans %}
{% trans %}Halfmove clock{% endtrans %}0{% trans %}Half-moves since the last capture or pawn move.{% endtrans %}
{% trans %}Fullmove number{% endtrans %}1{% trans %}The number of the current full move, starting at 1.{% endtrans %}

{% trans %}ChessFEN distinguishes the first field as a Placement from the six-field Full FEN. A picture can only reveal where the pieces stand, so recognition returns a Placement; the side to move is chosen by the caller and the remaining fields default to - - 0 1.{% endtrans %}

{% trans %}Where ChessFEN uses FEN{% endtrans %}

  • {% trans %}Recognition reads a board image and returns its Placement, with a per-square breakdown.{% endtrans %}
  • {% trans %}PGN navigation exports the Full FEN after any half-move.{% endtrans %}
  • {% trans %}Rendering turns any syntactically valid FEN into a board image.{% endtrans %}

{% trans %}Frequently asked questions{% endtrans %}

{% trans %}Is a Placement a Full FEN?{% endtrans %}

{% trans %}No. A Placement only says where the pieces stand; a Full FEN adds the five metadata fields.{% endtrans %}

{% trans %}Why is the side to move not recognized?{% endtrans %}

{% trans %}A Board image cannot show whose turn it is, so Recognition lets you choose White or Black.{% endtrans %}

{% trans %}Can I render illegal positions?{% endtrans %}

{% trans %}Yes. A syntactically valid FEN is rendered even when the position is illegal, with warnings.{% endtrans %}
