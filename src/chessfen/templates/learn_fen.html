{% trans %}Understanding FEN{% endtrans %}

{% trans %}FEN (Forsyth–Edwards Notation) is the standard text format for a chess position. ChessFEN uses it to pass positions between board images, PGN games, and rendered boards.{% endtrans %}

{% trans %}Piece placement{% endtrans %}

{% trans %}A FEN string starts with the piece placement: eight ranks from rank 8 down to rank 1, separated by /.{% endtrans %}

{% trans %}Uppercase letters stand for White pieces (K, Q, R, B, N, P) and lowercase letters for Black pieces. Digits encode runs of empty squares.{% endtrans %}

rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR

{% trans %}That is the starting position.{% endtrans %}

{% trans %}The other five fields{% endtrans %}

{% trans %}A complete FEN adds five space-separated fields: the side to move (w or b), castling rights (KQkq, or - for none), an en passant target square (or -), the halfmove clock, and the fullmove number.{% endtrans %}

rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1

{% trans %}ChessFEN distinguishes the first field as a Placement from the six-field Full FEN. A picture can only reveal where the pieces stand, so recognition returns a Placement; the side to move is chosen by the caller and the remaining fields default to - - 0 1.{% endtrans %}

{% trans %}Where ChessFEN uses FEN{% endtrans %}

  • {% trans %}Recognition reads a board image and returns its Placement, with a per-square breakdown.{% endtrans %}
  • {% trans %}PGN navigation exports the Full FEN after any half-move.{% endtrans %}
  • {% trans %}Rendering turns any syntactically valid FEN into a board image.{% endtrans %}
