{% trans %}Tags and moves{% endtrans %}

{% trans %}A game begins with tag pairs in square brackets, followed by the moves in numbered pairs — White's move, then Black's.{% endtrans %}

PGN 
[White "Alice"]
[Black "Bob"]
[Result "1-0"]

1. e4 e5 2. Nf3 Nc6 3. Bb5 a6 1-0

{% trans %}Moves, half-moves and plies{% endtrans %}

{% trans %}Each numbered move contains up to two half-moves, or plies. White's Nth move ends at ply 2N-1 and Black's Nth move at ply 2N; ply 0 is the initial position.{% endtrans %}

{% trans %}ChessFEN lets you pick exactly that half-move and exports the resulting Full FEN.{% endtrans %}

{% trans %}Term{% endtrans %}{% trans %}Example{% endtrans %}{% trans %}Meaning{% endtrans %}
{% trans %}Tag pair{% endtrans %}[White "Alice"]{% trans %}Metadata about the Game.{% endtrans %}
{% trans %}Move number{% endtrans %}1.{% trans %}Starts a full move; Black's reply follows.{% endtrans %}
{% trans %}Ply{% endtrans %}2N-1{% trans %}One half-move; White's Nth move ends at ply 2N-1 and Black's at 2N.{% endtrans %}
{% trans %}Variation{% endtrans %}(1. d4 d5){% trans %}An alternative line; ChessFEN ignores variations.{% endtrans %}
{% trans %}Result{% endtrans %}1-0{% trans %}The Game outcome: 1-0, 0-1, 1/2-1/2, or *.{% endtrans %}

{% trans %}Mainline and variations{% endtrans %}

{% trans %}Parentheses contain variations — alternative lines that were considered but not played. ChessFEN follows only the mainline and ignores variations; a PGN document with unparseable games is rejected so that no wrong position is served.{% endtrans %}

PGN 
1. e4 (1. d4 d5) e5 2. Nf3 *

{% trans %}Frequently asked questions{% endtrans %}

{% trans %}Are variations included?{% endtrans %}

{% trans %}No. Only the Mainline is followed; parenthesized variations are ignored.{% endtrans %}

{% trans %}What happens to a malformed PGN?{% endtrans %}

{% trans %}The whole document is rejected so that no wrong Position is served.{% endtrans %}
